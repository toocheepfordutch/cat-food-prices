Privacyverklaring

Deze website (Kattenvoer Prijsvergelijker (幼貓飼料比價)) is een prijsvergelijkingssite voor kattenvoer, kattenbakvulling en verzorgingsproducten voor huisdieren, met prijzen van webwinkels die leveren in Nederland. De site wordt beheerd door Yi Trading (eenmanszaak), ingeschreven bij de Kamer van Koophandel onder nummer 42131151, gevestigd te Rotterdam, Nederland. Contact: yicptcg@gmail.com.

Welke gegevens verwerken wij?

Deze website heeft geen accounts, geen formulieren en geen nieuwsbrief. Wij verzamelen zelf geen persoonsgegevens van bezoekers en verkopen geen gegevens aan derden.

Cookies en opslag

Deze website plaatst geen tracking- of advertentiecookies. Alleen functionele opslag in uw browser (localStorage) kan worden gebruikt om uw taal- of weergavevoorkeur te onthouden. De site wordt gehost via GitHub Pages; GitHub kan technische loggegevens (zoals IP-adres) verwerken volgens het privacybeleid van GitHub.

Externe links

Productlinks verwijzen naar externe webwinkels. Zodra u doorklikt, geldt het privacybeleid van die webwinkel. Sommige links zijn affiliate links; zie onze affiliate disclosure.

Donaties

Vrijwillige donaties lopen via Stripe. Wij ontvangen geen betaalgegevens; Stripe verwerkt die volgens zijn eigen privacybeleid.

Uw rechten

Omdat wij geen persoonsgegevens van bezoekers opslaan, valt er doorgaans niets op te vragen of te verwijderen. Vragen hierover kunt u stellen via yicptcg@gmail.com. U heeft ook het recht een klacht in te dienen bij de Autoriteit Persoonsgegevens.
